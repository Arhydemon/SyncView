# SyncView — совместный просмотр видео + чат (Flask + Socket.IO)

SyncView — локальный веб-сервис для совместного просмотра видео в реальном времени: один человек запускает сервер на своём ПК, остальные подключаются по IP в той же сети (Wi-Fi/роутер).  
Есть комнаты (приватные и публичные), синхронизация плеера, чат с историей, онлайн-список, загрузка mp4 на сервер.

---

## Возможности

### Комнаты
- Создание комнаты (название + ссылка на видео)
- Публичные комнаты (видны в разделе **Public**)
- Приватные комнаты (вход по коду)
- Код комнаты (например `AB12CD`) для входа/приглашения

### Видео (HTML5)
- Встроенный HTML5-плеер
- Синхронизация действий у всех участников:
  - Play / Pause
  - Seek (перемотка)
  - Периодический Sync (подгон времени)
- Ограничения управления (пример):
  - В публичной комнате управлять видео может только создатель (host)

### Чат
- Сообщения в реальном времени (Socket.IO)
- История чата при входе в комнату
- Системные сообщения (вход/выход)

### Онлайн (presence)
- Счётчик онлайн-пользователей в комнате
- Список кто сейчас онлайн в комнате

### Загрузка видео
- Upload mp4 на сервер → файл сохраняется в `app/static/uploads/`
- Ссылка на видео: `/static/uploads/<file>.mp4`

### Удаление комнаты
- Удалить комнату может только создатель (host)
- При удалении чистятся: сообщения, участники, сама комната

### Reset проекта (с нуля)
- Очистка БД + папки uploads одной командой/батником
